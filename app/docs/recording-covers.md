# 录像封面

归档完成后自动生成 960×540 JPEG：优先使用质量合格的原直播封面；否则从录像 6%–90% 均匀抽取 24 帧，用本地 YuNet 人脸检测、亮度、对比度及人脸清晰度评分筛选，并去除相似候选；没有合适画面时使用成员照片。所有有图片的封面均完整居中，背景用同一张图虚化填满；不裁切人物、不额外叠加文字或彩色侧栏。检测只识别人脸位置，不判断成员身份，也不能保证避开所有闭眼、表情或部分遮挡。

后台「封面设置」可为每位成员保存照片。尚未设置照片时尝试口袋48成员头像，再使用中性的居中姓名封面。图片封面统一使用背景虚化样式。旧版候选缓存自动失效，打开「选择封面」即可生成新样式；已选封面保留，确认新候选后再保存，已有 B站草稿需单独同步。

「录像归档」的「选择封面」显示原封面、最多 6 张去重截图和成员模板，标明推荐、时间位置和不建议使用的原因。支持手动选候选、重新筛选以及上传小于 1.4 MB 的 JPG/PNG/WebP。勾选未上传录像可批量重新生成（每批最多 100 条），进度在页面显示；批量任务在服务重启时终止，已成功保存的结果保留，可重新勾选剩余项。

上传队列将本地图片上传 B站，再使用返回地址保存草稿。封面失败保留录像，上传任务可重试。队列中的录像禁止手动修改封面。已有草稿可先选择本地封面，再点击「同步到 B站草稿」：备份完整草稿信息，仅调用 draft/update 更换 cover，保留视频分P和其他投稿字段，并重新读取草稿核对结果；失败不自动重试或重新创建草稿。尚未同步时页面明确标记「B站待同步」。

旧草稿按 draftId 匹配本地录像；缺少 ID 时通过草稿 CID 与上传记录的 uposBizId 精确匹配，只有唯一匹配才建立关联，不按标题猜测。B站草稿卡片有唯一关联录像时提供「选择封面」入口。未关联录像或已发布投稿请在 B站创作中心修改。

依赖 ffmpeg、ffprobe、OpenCV 4.11.0.86、Pillow 11.3.0 与随源码发布的 YuNet 模型。默认复用 /opt/asr-venv/bin/python；支持 COVER_PYTHON_BIN / FFMPEG_BIN / FFPROBE_BIN / COVER_FONT。COVERS_DIR 需持久化，默认 DATA_DIR/covers。照片设置保存在 DATA_DIR/cover_settings.json。接口均位于管理员认证范围内，候选文件必须属于指定录像。旧封面保留用于回滚；临时抽帧目录在完成或失败后清理。新增 Python 依赖须通过完整 Dockerfile 构建。

本轮验证范围与线上结果见 [1.13.0 发布核对](releases/1.13.0-audit.md)。
