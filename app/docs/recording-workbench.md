# 录像工作台（1.2.0）

## 时间线剪辑

在详情页播放器下使用时间线。点击轨道定位播放位置，拖动蓝色保留区域两端调整边界；靠近播放标记时吸附。加减按钮缩放 1–32 倍，轨道可横向滚动。聚焦时间线或边界后，方向键微调 0.1 秒，Shift 配合调整 1 秒。

点击「在标记处分割」生成两个保留段，在下方成片轨道选中不需要的段后删除。删除只改变当前剪辑，不删除原片；可撤销最近 50 次编辑或恢复整段。每段至少 1 秒，最多 30 段，总成片最长 2 小时。未导出的编辑在刷新或离开页面后重置。

「预览成片」自动跳过未保留的时间范围；「拼接导出 MP4」按原片时间顺序合成一个视频。浏览器预览不是最终编码，精确输出由 FFmpeg 完成。导出记录保留全部 segments 起止点，可下载或进入 B站草稿。桌面播放器在滚动编辑时保持显示。

`POST /recordings/:id/clips` 新增兼容参数：`{ "segments": [{ "start": 0, "end": 10 }, { "start": 20, "end": 30 }], "title": "成片标题" }`。服务器排序、校验非重叠和真实媒体时长，旧版 start/end 参数继续支持。

时间线当前不含字幕块与 AI 高光，这些随第二阶段接入。

在管理后台的「录像归档」点击录像标题，打开独立详情页。播放器加载时长后，可以输入起止秒数（支持小数），或播放到目标位置后点击「标记当前位置」。使用「预览选段」检查范围，再生成 MP4 片段。

每段最短 1 秒，最长 2 小时。生成过程在后台排队，可以离开页面。片段库自动刷新状态；完成后可播放、下载，或加入现有 B站草稿队列。上传需要已有 B站登录状态。片段标题会保留到草稿，不再套用原片的归档命名规则。

片段作为独立归档保存，记录来源录像、起止时间和生成进度。原片不会被修改。删除已完成的原片不会删除独立片段；来源记录保留，但不可继续播放已删除的原片。片段可继续剪辑，时间相对于当前片段。

## 队列与异常

- 最多 20 个待处理/处理中的剪辑，同时只执行一个 FFmpeg 转码，视频编码单线程。
- 启动下一项前检查录制、等待续播和归档状态，优先等待这些任务结束。已开始的剪辑不会因新直播到来强制中断。
- 范围在提交时初检，在媒体探测后再次核对真实时长。输出 H.264/AAC MP4，生成后检查时长再标记成功。
- 排队及处理中禁止删除来源录像和剪辑文件。重启中断的转码标记为失败，可手动重试；尚未开始的队列继续处理。
- 失败会保留错误状态，尽可能清理本次生成的不完整文件。因权限问题未清理的文件仍关联到失败记录，可从归档管理删除。
- 页面草稿按钮只加入草稿队列，不直接发布视频。

## API

均沿用 `/api/admin` 会话认证。

- `GET /recordings/:id`：录像信息。
- `GET /recordings/:id/clips`：来源录像的片段列表。
- `POST /recordings/:id/clips`：`{ "start": 10.25, "end": 42.5, "title": "片段标题" }`，返回 202 和独立归档记录。重复提交同一处理中区间复用任务。
- `POST /recordings/:id/retry-clip`：失败任务重新排队。
- 片段复用原有 `/file`、`/download`、`/upload` 和删除接口。
