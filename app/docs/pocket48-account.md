# 口袋48账号工作台

入口：后台侧栏「口袋48」，路径 /admin/pocket48。

- 个人资料：昵称、UID、头像、等级、签名，独立刷新登录状态。登录入口复用原有短信验证弹窗。
- 签到：查询签到信息、手动执行签到、成功后刷新状态。
- 房间：账号房间列表、名称或 ID 搜索、手动输入 ID、房主消息、历史消息分页。
- 监听：添加或移除房间、开始或停止监听、近期消息、各房间检查时间和错误提示。最多 30 个房间，每轮完成后等待至少 15 秒再继续，页面每 5 秒读取监听缓存。关闭页面后后端继续监听，服务重启后需重新配置。登录或退出清空旧监听状态。
- 消息目前展示文本；图片、语音等消息显示类型占位，不提供发送功能。

新增接口位于 /api/admin/pocket48/account，沿用管理端认证。上游业务失败不会包装成成功；个人资料采用白名单，避免返回凭据。

验证：前端生产构建成功；55 项后端测试通过；浏览器模拟接口测试覆盖资料、签到、消息分页、加入监听、开始停止监听及移动端溢出检查。预览图片使用模拟账号数据。

限制：尚未部署，尚未使用有效口袋48账号联调。现有口袋48接口的真实返回字段、权限限制及短信登录可用性需在有效登录后确认。全量前端测试仍有 6 项旧页面失败，涉及自动录制页面源码断言、成员数据快照、LoadingState 的服务端渲染 React 引用，以及系统设置和回放样式断言；新增交互测试通过。

视觉方向：延续既有浅灰背景、白色卡片与蓝色操作色；上方账号和签到卡片，下方房间列表与消息阅读区；窄屏纵向排列，沿用项目字体。
