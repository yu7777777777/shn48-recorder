# 1.28.14 发布核对

- 发布日期：2026-10-24（北京时间）
- 触发原因：1.28.13 虽恢复了名单（900 人），但全部落为「未分组」，用户指出官网本身能正常显示分团与队伍
- 版本：1.28.13 → **1.28.14**（PATCH）

## 根因修正

1.28.13 的判断只对了一半：`h5.snh48.com` 确实坏了，但**官网并没有失去成员数据，只是换了接口域名**。

用容器内 Chromium 打开 `https://www.snh48.com/member_list.html` 抓包，真实请求为：

```
200 script https://h5.48.cn/resource/json/allmembers_0.jsonp?callback=get_members_success
200 script https://api.snh48.com/getmembertop.php?source=13&callback=...
```

`h5.48.cn/resource/json/allmembers_0.jsonp` 返回 `{"total":"761","rows":[...]}`，每行含 `gid/gname/tid/tname/sname/pocket_id`，即分团、队伍、口袋48用户 ID 齐全。`getmembertop.php`、`h5.snh48.com`、`www.snh48.com/resource/jsonp/members.php` 仍是 502，验证了换域判断。

## 修复

来源优先级（`members.js`）：

1. **官网现行 JSONP 接口**（首选，一次请求）：`source = official`
2. 旧的按分团目录（保留镜像覆盖能力）：`source = directory`
3. 房间名册（无分组，1.28.13 的行为，仅作最后兜底）：`source = room-map`

其他调整：

- 房间名册从必需项降为可选项，第三方 `abm48.com` 故障不再影响名单。
- 归一化放宽 `status` 判断：现行官网数据没有 `status` 字段；只有显式非 `99`（离团/下架）才排除。
- 新增 `source` 字段便于排障，`fallback` 语义不变。
- 顺带修正合并多个分团时同 id 成员被覆盖、队伍信息丢失的问题（旧目录路径同样受益）。
