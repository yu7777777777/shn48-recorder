### 与本次改动无关的既有失败

`server/test/*` 全量在本机为**129 通过 / 15 失败**、`client/test/pocket48-login-ui.test.js` 失败，均为**环境与既有缺陷**，改动前后表现一致：

- 15 个服务端失败全部依赖 `ffprobe`、`/opt/asr-venv/bin/python`、离线模型或封面渲染运行时，本机 Windows 未安装（报 `spawn ffprobe ENOENT`）。
- `pocket48-login-ui.test.js` 属 1.17.9 体检已记录的**预存缺陷**，位于 `AutoRecord` 登录页：mock 返回 401 后 `lib/api.js` 的响应拦截器会把浏览器重定向到 `/admin/login`，页面内的错误提示来不及渲染。已用独立探针复现该重定向，证明与口袋48 页面代码无关（`lib/api.js`、`AutoRecord.jsx` 本轮均未改动）。

## 回滚方式

```bash
cd /opt/shn48
sed -i 's|image: shn48-shn48:1.20.0|image: shn48-shn48:1.19.0|' docker-compose.yml
docker-compose -f docker-compose.yml -f docker-compose.public.yml up -d
```

`shn48-shn48:1.19.0` 镜像仍在本地，无需重新构建。回滚后 1.20.0 新增的 `pocket48_follows.json` 会被旧版本忽略，不影响运行。
