# 1.30.0 发布核对

- 发布日期：2026-10-24（北京时间）
- 触发原因：用户反馈成员名单按队伍分组后，531 人全部展开要翻到底才能找到靠后的队伍
- 版本：1.29.0 → **1.30.0**（MINOR，兼容新增）

## 变更

- 队伍标题改为折叠控件（`<h3><button aria-expanded>`），整条标题可点，点一下收起/展开该队。
- 折叠状态持久化到 `localStorage` 的 `pocket48.collapsedTeams`。
- 搜索框下新增「收起全部队伍 / 展开全部队伍」与「已收起 N / M」。
- 一键收起时，正在阅读的成员所在队伍保持展开（`heldKey` 判定），避免选中行消失。
- 窄屏 ≤1150px（横向条布局）下不折叠，箭头隐藏。
