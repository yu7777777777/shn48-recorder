## 根因与修复

- 旧代码把完整清单一次交给 FFmpeg 合并，再用清单总时长与 MP4 时长作 2 秒 / 0.2% 比较。官方重连时间轴会在合并中产生偏差，固定输入重复触发失败。
- 1.32.2 按 discontinuity 分段归零、无损拼接；逐段及成片核对画面/音频包数。仅在包数完全一致时，额外允许一个边界分片以内且不超过连续段 1% 的误差；缺资源、下载截断、无画面、格式变化、包数不符和解码错误继续拒绝。
- 失败保留不含上游 URL / token 的 `validation.json`，错误可显示实际测量值；定时扫描保留失败原因。
- 1.32.3 将旧缓存的重新下载放进 `audit-timeline-v1` 独立候选目录，通过比较后才更新归档引用。保留原缓存及失败候选诊断。
