# 1.33.0 发布核验（版本更新检测）

发布日期：2026-11-14。发布方式：**仓库驱动**（GitHub `main` @ `195ad8a` → 服务器 `scripts/update-from-repo.sh`），是「新版本检测 + 人工确认一键更新」机制的首次实机使用。

## 内容

- 新增 `server/modules/update-checker/`：定时调用 GitHub Contents API 比对仓库 `app/VERSION` 与运行版本；发现更新经既有通知系统推送（事件 `update_available`，每版本一次）。
- 新增管理端「版本更新」页（`/admin/update`）与 `/api/admin/update`（settings GET/PUT + 立即检查）；PAT 仅存数据目录，接口只回显 `tokenSet`。
- 新增 `scripts/update-from-repo.sh`（部署为 `/opt/shn48/scripts/update-from-repo.sh`）：预检（健康/活动任务/磁盘）→ Deploy Key 浅克隆 → 版本前进校验 → docker build → compose 备份与切换 → healthy 等待 → 健康接口与运行文件哈希核验；失败自动回滚。
- 通知事件列表新增「新版本可用」（默认开启）；`NotifySettings` 页事件开关同步。

## 测试与质量闸门

- 新增 `server/test/update-checker.test.js` 7 项全过（配置校验/掩码/版本比对/去重提醒/失败记录/状态持久化）。
