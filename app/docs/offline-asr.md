# 离线识别与字幕纠错

## 使用流程

在「字幕与 AI 设置」选择服务器离线识别，下载 tiny 或 base，点击「测试离线识别」对照固定音频原文，再保存设置。归档详情点击「生成字幕」，完成后按需点击「AI 文字纠错」，最后生成章节、精彩片段或翻译。也可直接导入 SRT 后纠错。

模型第一次安装需要联网下载公开模型文件；识别使用服务器本地模型和 CPU，不上传音轨、不动态下载模型。AI 纠错、章节和翻译会把字幕文字及相关词库发送到配置的文本服务。纠错是独立操作，不会在转写结束时自动消费文本接口。

tiny 更快，base 通常更准确，但均可能误识别人名、口音及背景音乐。词库的标准词和别名用于识别提示、AI 纠错参考，不是强制全文替换规则。AI 无法保证恢复听不清的原话，重要片段需对照录音。

纠错保留每条原文和时间戳，支持显示原文及恢复；所有批次验证通过后才统一保存。成功纠错或恢复原文会清空旧翻译、章节和精彩片段，可重新生成。操作前分析保存在 `analysis_<id>_before_correction.json` / `_before_restore.json`；各类型保留最近一次备份。

## 资源和恢复

- 当前服务器 2 核、约 1.7 GB 内存，使用 CPU INT8、进程 nice 10；CPU 线程数由 `ASR_CPU_THREADS` 控制，默认 `min(4, CPU 核数)`。
- 一次只运行一个离线任务；进度按分块保存（默认每块 600 秒，`ASR_CHUNK_SECONDS` 可调），失败或中断后重试从第一个未完成分块继续。录制进行中任务在启动前闸门等待，不终止正在运行的识别进程；等待中的任务在录制结束后自动继续。
- 模型安装与离线识别互斥，安装开始时禁止正在录制。下载过程中若新录制开始，下载可能继续；安装验证仅短暂加载模型。
- 服务重启会标记未完成任务失败；手动重试从已完成音轨分块继续。切换模型或词库会重新识别，不能混用不同模型的进度；重新识别前若已有字幕，会先备份为 `analysis_<id>_before_retranscribe.json`（各类型保留最近一次）。
- 模型在 `DATA_DIR/asr-models`，随数据目录持久化，不进入源码包。删除归档不删除共享模型。

## 版本和升级

引擎固定 `faster-whisper==1.2.1`，Python 虚拟环境 `/opt/asr-venv`。当前支持：

| 模型 | 上游仓库 | 固定 revision |
| --- | --- | --- |
| tiny | Systran/faster-whisper-tiny | d90ca5fe260221311c53c58e660288d3deb8d356 |
| base | Systran/faster-whisper-base | ebe41f70d5b6dfa9166e2c581c45c9c0cfc57b66 |

模型能力升级可先下载另一档、测试再切换。增加模型、升级 Python 引擎需修改白名单及依赖，真实音频回归后随应用发布，更新 CHANGELOG 与版本号。不得直接更新生产依赖或覆盖正在使用的模型。

`OFFLINE_PYTHON` 可覆盖 Python 路径；`OFFLINE_MODELS_DIR` 可覆盖模型目录。`HF_ENDPOINT` 仅影响安装时公开模型的下载源，默认 Hugging Face；服务器访问受限可配置 HTTPS 镜像，首次部署核对模型 SHA-256。推理始终使用本地目录与 `local_files_only=True`。

Docker 全量构建会安装 Python 和依赖。增量发布使用已验证、包含离线引擎的基础镜像，Dockerfile.release 检查 Python 存在。若历史镜像达到层数限制，应从干净创建的源镜像容器导出压平，不能导出运行中的生产容器；恢复入口、环境、工作目录，重新测试并记录来源镜像哈希。
